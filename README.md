# Production Optimization Service

Сервис оптимизации производственного расписания на основе математической модели (варианты A и B).\
Реализован на Python 3.10, FastAPI и CVXPY. Сервис принимает данные о заказах, производительности бригад и параметрах модели, строит оптимальный график производства и возвращает план на горизонте 30 дней.

* * * * *

1\. Функциональное назначение
-----------------------------

Сервис решает задачу планирования загрузки бригад при производстве оборудования.\
Основные возможности:

-   Формирование плана производства на горизонт 30 дней
-   Учёт разных типов изделий (серийные, несерийные)
-   Поддержка производительности по бригадам и изделиям
-   Учёт дедлайнов заказов
-   Учет переработок, недогрузок и просрочек
-   Два варианта модели:
    -   **Модель A:** базовый вариант с фиксированными коэффициентами
    -   **Модель B:** расширенный вариант с параметрами α и β для управления приоритетами недогрузки и переработки
-   Динамическое изменение производительности в будущем через месячные коэффициенты потерь ресурса
-   Возврат детального план-графика с распределением задач по дням и бригадам


* * * * *

2\. API эндпоинты
-----------------

### POST `/api/v1/optimize/model-a`

Запуск оптимизации по модели A.

**Input:**

-   дата начала периода

-   горизонт планирования

-   список заказов

-   производительность бригад

-   коэффициенты k (штрафы)

**Output:**

-   objective_value

-   производственный план по дням и бригадам

-   просрочки заказов

* * * * *

### POST `/api/v1/optimize/model-b`

Запуск оптимизации по модели B (с параметрами α и β).

**Дополнительно:**

-   Параметры α и β задают относительную важность переработки и недогрузки.

* * * * *

3\. Формат входных данных (пример)
----------------------------------

```json
{
  "session_id": 101,
  "start_date": "2025-01-01",
  "num_days": 30,
  "orders": [
    {
      "order_id": 1,
      "product_id": 10,
      "production_type": "serial",
      "quantity": 30,
      "deadline_date": "2025-01-20"
    }
  ],
  "team_productivity": [
    {
      "team_id": 1,
      "product_id": 10,
      "production_type": "serial",
      "productivity": 0.6
    }
  ],
  "params": {
    "k_tardy_default": 1000000.0,
    "k_under": 100.0,
    "k_over": 200.0,
    "delta_buffer": 0.17,
    "alpha": 0.5,
    "beta": 0.5
  }
}
```

4\. Локальный запуск без Docker
-------------------------------

`conda create -n optimization_env python=3.10`

`conda activate optimization_env`

`pip install -r requirements.txt`

`uvicorn app.main:app --reload`


Документация Swagger:\

`http://localhost:8000/docs`


* * * * *

5\. Запуск через Docker
-----------------------

### Сборка

`docker build -t optimization_service .`

### Запуск

`docker run -p 8000:8000 optimization_service`

### Docker Compose

`docker compose up --build`

* * * * *

--------------------------

-   Python 3.10+

-   Linux или Windows с установленными библиотеками BLAS/LAPACK
